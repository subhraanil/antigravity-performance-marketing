Track your real Google SERP keyword rankings directly inside WordPress with zero domain limits and zero throttling.

== Description ==
An unrestricted, lightweight Google keyword rank checker built for WordPress. Powered by Serper.dev API to deliver 100% accurate Google positions with zero captchas.

= Features =
* Track any keyword directly from your WordPress Admin panel (`wp-admin`).
* Displays your Google Rank (1–100) with color badges and ranked landing page URL.
* Track rank movements over time (▲ +2, ▼ -1, NEW).
* Real-time progress bar scanning to avoid PHP timeout limits.
* Zero domain restrictions: Track your own site, client sites, or competitor sites.
* 1-Click CSV export for reporting.

== Installation ==
1. Go to Plugins > Add New > Upload Plugin.
2. Choose `wp-rank-tracker.zip` and click Install Now.
3. Activate the plugin.
4. Go to the new "Rank Tracker" menu in your WordPress dashboard.
