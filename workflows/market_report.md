---
description: Fetch Nifty 50 and HDFC Small Cap data and generate a daily HTML report with Moving Averages (50, 100, 200 SMA).
---

1. Run the data fetch and analytical report generation script.
// turbo
2. Run the command: `python fetch_and_report.py`
3. The report will be generated as `market_report.html` in the root directory.
4. Open the `market_report.html` file in your browser.
5. **Interactive features**: 
   - View the dual-axis chart (Nifty 50 on Left, HDFC Small Cap on Right).
   - Click on the legend items (e.g., "Nifty 50 SMA", "HDFC 200 SMA") to toggle moving averages on/off.
   - Hover over the chart for unified date-based tooltips.
