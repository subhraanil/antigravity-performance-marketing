3. Critical "Smoking Gun" Issues (Empirically Verified)

1. Default Next.js 13 Template Description in Production

Observed: Meta description on homepage and /efficiency reads: "An open source application built using the new router, server components and everything new in Next.js 13."
Impact: This exact string from the shadcn/taxonomy starter kit appears directly in Google search snippets, destroying organic CTR.

2. Primary CTA Links to a 25-Word "Under Construction" Page (/efficiency)

Observed: The prominent homepage CTA "How We Find Efficient Solutions" links to /efficiency, which contains only 25 words stating: "Under Construction. This page is currently being built. Please check back soon."
Impact: Returns HTTP 200 without a noindex tag. Zero H1s, zero value, causing 100% of prospects to bounce.

3. Severe Heading Dilution (7 Separate H1 Tags on Homepage)

Observed: Homepage marks up 7 separate <h1> tags (the main slogan plus all 6 industry tabs: Aviation, Marine, Medical, Automotive, Industrial, Consumer).
Impact: Completely dilutes core topical focus. Industry tabs should be <h3>.

4. FAQ Answers Unmounted in Server HTML (Invisible to Googlebot)

Observed: On /faq, 14 high-value questions are displayed via Radix UI accordion. In server HTML, closed answers render with <div hidden=""></div> with zero inner text.
Impact: Crawlers see only 130 words of question headings and zero answers, blocking FAQ Rich Snippets.

5. Live Production Legal Pages Contain Latin Lorem Ipsum ('Taxonomy App')

Observed: /privacy and /terms are live on production containing raw Latin filler text referencing "Taxonomy App". Neither is linked in the footer.
Impact: Destroys enterprise B2B credibility and Google E-E-A-T.

6. Missing XML Sitemap (HTTP 404) & Canonical Tags Across 100% of Pages

Observed: https://www.panelright.com/sitemap.xml returns 404, and 0 pages have <link rel="canonical">.
Impact: Crawlers receive no sitemap guidance, and Screaming Frog flags missing canonicals across all URLs.

4. Next.js Code Implementations (Deploy in < 2 Hours)

A. Dynamic XML Sitemap (app/sitemap.ts):

import { MetadataRoute } from 'next';
export default function sitemap(): MetadataRoute.Sitemap {
  const base = 'https://www.panelright.com';
  return [
    { url: base, lastModified: new Date(), changeFrequency: 'weekly', priority: 1.0 },
    { url: `${base}/faq`, lastModified: new Date(), changeFrequency: 'monthly', priority: 0.8 },
    { url: `${base}/efficiency`, lastModified: new Date(), changeFrequency: 'monthly', priority: 0.8 },
    { url: `${base}/privacy`, lastModified: new Date(), changeFrequency: 'yearly', priority: 0.3 },
    { url: `${base}/terms`, lastModified: new Date(), changeFrequency: 'yearly', priority: 0.3 },
  ];
}
