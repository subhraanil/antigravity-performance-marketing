Technical Hosting is Fast, But SEO Foundation is Severely Incomplete

PanelRight is hosted on modern Vercel Edge infrastructure delivering lightning-fast response times (TTFB: 68 ms). However, the site suffers from zero organic search visibility because the development team deployed the site with Next.js 13 boilerplate template descriptions, 7 H1 tags on the homepage, an 'Under Construction' placeholder page linked from the primary CTA, unmounted FAQ answers, and missing sitemaps/canonicals.

Critical "Smoking Gun" Defects

1. Default Next.js 13 Template Description Active in Production

Observed: Meta description on homepage reads: "An open source application built using the new router, server components and everything new in Next.js 13." This developer boilerplate from the shadcn/taxonomy starter kit appears in live Google search snippets.

2. Primary CTA Links to a 25-Word "Under Construction" Page (/efficiency)

Observed: The homepage CTA "How We Find Efficient Solutions" links to /efficiency, which displays only: "Under Construction. This page is currently being built. Please check back soon." Returns HTTP 200 without a noindex tag.

3. Heading Dilution: 7 Separate H1 Tags on Homepage

Observed: The homepage marks up every industry tab (Aviation, Marine, Medical, Automotive, Industrial, Consumer) as an <h1>, completely diluting core keyword focus.

4. FAQ Answers Unmounted in Server-Rendered HTML (Invisible to Crawlers)

Observed: Radix UI accordion renders closed answers with <div hidden=""></div>. Crawlers see 130 words of question headings and zero answers, blocking FAQ Rich Snippets.

5. Live Legal Pages Contain Latin Lorem Ipsum ('Taxonomy App')

Observed: /privacy and /terms are live on production and contain unedited Latin filler text referencing "Taxonomy App".
